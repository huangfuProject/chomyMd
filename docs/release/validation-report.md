# Chomy 1.0.17 版本验证记录

日期：2026-10-14。验证主机：macOS、Apple M1 Max、arm64。

发行优化：压缩 main/preload，保留运行时名称和许可注释；运行资源白名单排除开发文件及冗余图标；保留中英语言并裁剪其他 Electron 语言包；DMG 改用 ULMO/LZMA 压缩。未替换运行时或删除 GPU/软件渲染回退等必需库。

现场 CleanMyMac 明细表明 1.7 GB 为 5 份同名应用的合计，其中 3 份是之前生成的回滚备份。旧备份压缩、解压并逐文件验证后再归档，用户截图、恢复记录及云配置保留。

## 验证与交付

`pnpm check` 通过：lint、类型、48 项单元测试和格式检查。新增打包策略测试验证运行文件白名单、许可保留、中英语言资源保留及上游布局异常拒绝。只读 ULMO DMG 的安装副本在原构建不可用时，完整 26 项窗口回归通过（约 1.1 分钟），包含公式、图片/截图持久存储、代码高亮、主题、恢复、外部冲突及导出；14 条相对 framework 链接有效。

此前 3 份回滚应用由 993,150,023 字节压缩为 408,731,621 字节，每份均解压后逐文件比较 SHA-256、权限及符号链接通过。升级新增的 1.0.16 回滚应用也已压缩并逐文件验证：331,052,913 字节变为 136,244,984 字节。当前开发构建与已生成发行 ZIP 解压副本的每个文件、权限和 14 条链接一致后，移除该重复应用目录；保留 ZIP 和 DMG，可完整恢复。开发副本归档后，以已安装应用独立运行启动/安全桥回归通过，未依赖开发应用路径。

安装 1.0.17 的 ASAR 与通过验证的构建一致（SHA-256：88ba53aa3164601c2bc9089afe28326980ce6ff2957d75a296fbae0ca29aacfa）。同样的文件字节在本机复制安装后有不同文件系统分配开销，因此分别记录发行逻辑体积、构建分配和实际安装分配，不混用统计口径。

CleanMyMac 的“操作→刷新”重新扫描后，Chomy 合计由 1.7 GB 变为 304.2 MB；包括当前安装应用及关联用户数据。刷新前显示过期副本列表，因此不能只用清理工具缓存的合计判断单份应用大小。此次用户数据未清理，压缩备份和发行包仍保留以便恢复。
