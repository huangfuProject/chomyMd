| --------------- | -------- | --------------------------------------------------------------- |
| 侧栏边界        | R01/R02  | 约x=640截图像素；随窗口大小变化                                 |
| 正文范围        | R02      | 左约1084、右约3015，宽约1930截图像素；需统一逻辑窗口后复测      |
| 正文/标题       | R02      | 黑色正文、H1/H2明显增大且底部细线；确切字体、字号、行高尚未核验 |
| 引用            | R02      | 浅灰左边线与缩进，正文偏灰                                      |

| 暗色/当前主题名 | 未切换   | 尚未观察暗色效果，不根据主题菜单名称推断当前选择                |
