# Chomy 1.0.14 版本验证记录

日期：2026-10-14。验证主机：macOS、Apple M1 Max、arm64。

新增七牛云 Kodo 提供器和区域设置。连接测试使用签名的只读资源列举，上传使用限制空间与对象 key 的 multipart 令牌；凭据继续由系统 safeStorage 加密。上传取消、超时、失败保留本地副本和重试沿用统一流程。

图片与附件的新配置默认源文件路径；保留已经保存的用户偏好。修复选择/拖入入口及主进程路径解析对未保存文档的错误保存限制。未保存文档使用编码的绝对 file URL，首次保存迁移授权并保留 Markdown；恢复、重启及授权目标校验仍有效。已保存同卷原路径仍使用相对链接；跨卷可使用绝对 file URL。普通附件通过主进程验证后打开，不直接放开 file 协议访问。粘贴时若系统提供真实源文件句柄，复用插入原文件策略；内存截图使用独立二进制落盘流程。富文本链接视图仅补充 file URL，保留其他协议净化，点击仍由主进程检验授权。

剪贴板图片数据没有源文件路径，当前仍需保存文档后写入相邻 assets（或随后上传云端）；偏好说明和技术手册明确此边界。未来可考虑持久截图目录，此版本没有实现该独立策略。Typora 公共图片说明列明：原文件默认引用原路径，剪贴板数据先存入指定文件夹或服务器再插入引用。

## 验证与交付

`pnpm check` 通过：lint、严格类型、44 项单元测试、格式检查。七牛云协议服务器独立核验连接签名、上传令牌 HMAC、空间/key scope、时效、insertOnly、multipart 图片字节、拒绝请求与取消；原路径单元测试覆盖未保存插入、恢复、首次保存与重开。

安装副本窗口回归验证默认原路径在未保存文档中插入图片和文本附件，保存框被设为抛错仍插入成功；图片显示、普通附件打开、阅读预览、保存后重启、无 assets 副本，以及七牛云设置入口。复制模式与剪贴板粘贴回归保留。只读 DMG 的安装副本在原构建不可用时，完整 25 项窗口测试全部通过（约 1 分钟），14 条相对 framework 链接有效。最终生成 Mac APP、ZIP、DMG 及 Windows x64 便携 ZIP，7 项产物 SHA-256 见 artifact-manifest.json。

本机用户确认退出后，保留旧应用备份并安装 1.0.14；安装 ASAR 与通过测试的构建一致（SHA-256：27df0041b63aa8ef62ae60d57362a4c40c61c3c2a1af9e984f0d9b56b684da2a）。原生启动正常，偏好面板显示源文件路径及七牛云 Kodo，切换七牛云显示华东·浙江区域选择。检查后取消配置草稿，用户文档及恢复数据保留。
