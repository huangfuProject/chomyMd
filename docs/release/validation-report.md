# Chomy 1.0.11 版本验证记录

日期：2026-10-14。验证主机：macOS、Apple M1 Max、arm64。

按用户截图调整三个入口：左上文件树图标直接打开当前文档所在目录；右上大纲图标显示当前文档标题目录；字数和大纲之间增加圆形源码切换。侧栏原有视图选择菜单移到居中标题，仍可选择最近文件和大纲。

已保存文档不弹出目录选择器，未命名文档使用会话中已选择的目录，否则询问文件夹。目录扫描继续在main，renderer只能调用无路径参数的currentFolder白名单API；返回结果、发起frame和请求结构继续校验。扫描仍保留原有Markdown/txt过滤与数量、深度、符号链接限制。

新增入口使用现有源码转换操作，保留撤销、IME保护与未知语法保护；受保护文档从阅读模式也可以直接回到源码。本轮包含1.0.10强调输入修复。

窗口专项测试验证：已保存文件所在目录直接扫描且不调用选择器，嵌套Markdown文件树、大纲切换、四个标题控件的顺序、源码圆圈的双向切换。lint、类型、格式和42项单元测试通过。
