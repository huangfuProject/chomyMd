# Chomy 1.0.8 版本验证记录

日期：2026-10-13。验证主机：macOS 26.5.2、Apple M1 Max、arm64。

## 改动

按用户提供的Typora窗口截图，重新组织左右两列界面。全高320px侧栏、26px窗口按钮预留、30px侧栏标题行；大纲标题居中，左侧视图菜单、右侧搜索，“大纲内容为空”在剩余面板居中。大纲、文件树、最近文件仍可切换，过滤标题保留真实跳转索引。

正文32px标题栏采用文件名、“— 已编辑”、字数/统计弹窗、大纲与侧栏按钮，去除常驻新建/保存/设置等工具按钮及底部状态栏。文件标题弹窗提供原有操作，点击外部、Escape、选择菜单项可关闭。编辑工具和表格工具按需出现；错误、冲突、恢复与上传反馈保留。

macOS使用hidden原生标题栏，交通灯配置(12,10)；收起侧栏时文件标题避让交通灯。原生菜单顺序为Chomy、文件、编辑、段落、格式、显示、主题、窗口、帮助；主题菜单直接选择四种内置模式并可打开主题管理。新增命令继续受contracts白名单限制。应用名称和品牌保持Chomy。

自定义主题继续只作用于正文，不开放修改应用外壳。技术手册第13章补充布局、菜单、主题边界和截图复现方式。

## 验证结果

- lint、严格TypeScript、格式检查、40项单元测试通过。
- 开发目录完整22项E2E通过，49.6秒。新增布局、图标大小、原生菜单/交通灯坐标、视图切换、侧栏搜索、弹窗关闭、源码与暗色标题栏测试。
- 首轮20项通过，2项旧测试把已收起菜单中的保存按钮当成常驻按钮，修正测试定位后，3项文件保真回归通过，再完整重跑22项通过。没有删除测试或改变保存逻辑。
- 860×540逻辑窗口截图对照用户参考：侧栏320px、正文左偏移30px、标题左偏移62px。几何记录见[chrome-layout.json](../testing/chrome-layout.json)，实际运行截图见[界面对照](../testing/screenshots/chomy-chrome-reference.png)。明亮、暗色、表格工具、主题设置截图已重新生成并观察；发现并修正旧图标规则覆盖和暗色标题背景。

## 打包与安装

Mac APP、ZIP和DMG生成成功，hdiutil校验通过。只读DMG复制后的应用保留14条相对framework链接；移走原构建后，全部22项E2E通过，50.6秒，证明不依赖构建位置。Windows x64首次构建下载失败，使用此前已验证的Electron镜像重试后便携ZIP生成成功，不能据此宣称Windows10/11实机验收通过。7个关键产物摘要记录在[artifact-manifest.json](artifact-manifest.json)。

本机/Applications/Chomy.app已更新到1.0.8；检查旧进程为此前已保存的样本会话且恢复目录为空后，保留1.0.7应用备份再替换。新应用后台启动、进程存活，安装ASAR与验证构建的SHA-256一致。未改写用户文档和生产设置；桌面锁定期间不将后台启动称为原生视觉验收。

## 原生观察边界

本轮尝试原生窗口检查时Mac处于锁定状态，未能获取完整系统菜单和交通灯的原生截图。Electron原生菜单对象和交通灯API配置已在回归中验证；网页截图不包含系统菜单或交通灯，不能据此宣称原生控件逐像素一致。本轮针对用户截图中的窗口框架，尚不代表Typora全部菜单项、表格/代码浮层、源码退出方式和全部主题的完整复刻；差异继续见[参考差异表](../../research/typora-1.4/compatibility-differences.md)。

Windows10/11人工安装、原生输入法、真实云桶与签名公证仍依照[平台清单](platform-checklist.md)。之前修复的输入法星号强调、代码语言/↓退出、相对framework链接保持回归覆盖；此前1.0.7记录保留在[历史验证](validation-1.0.7.md)。
