## 2026-10-13 排版观察

使用自建 layout-reference.md 在现有 Typora 窗口打开，未修改配置或安装文件。参考截图为 3456×2168 物理像素；Chomy 对照以 1728×1084 CSS 像素、2 倍设备缩放捕获。只观察界面，未复制参考 CSS、字体或代码。

参考短表格单行约 38 CSS px，细灰边框、灰色加粗表头、首行正文白色、次行灰色，说明列按内容占用较多宽度。多行内容垂直居中。块公式居中，当前配置在右侧显示 (1)、(2)。当前配置下行内 $E=mc^2$ 保持字面文本；不能把它推定为所有 Typora 配置的行为。

Chomy 1.0.2 单行实测 38.59 CSS px，三个列宽约 217/526/217 px；保留 Markdown 列对齐。原 fixture 含公式和 HTML，使用源码与阅读模式；可视编辑截图使用去除公式及 HTML 的派生文件。Chomy 的 KaTeX 与参考公式渲染仍有字形、度量差异，不宣称逐像素一致。
