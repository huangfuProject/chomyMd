# Chomy 1.0.10 版本验证记录

日期：2026-10-14。验证主机：macOS、Apple M1 Max、arm64。

用户反馈先逐键输入两个星号、左移到中间再输入ddd，会保存为转义星号。此前只在新输入星号时触发完整强调转换，漏掉了闭合星号已经存在的输入顺序。

新增光标所在既有分隔符配对转换，转换后保持光标内的强调标记，连续输入ddd均为斜体；支持粗体和中文组合输入。候选必须包围提交位置，保留代码、显式转义、非空选区、未知解析内容的保护。原先闭合星号后继续输入普通正文仍清除storedMarks。IME提交位置不被后续确认空格覆盖，已有空格/回车回归继续覆盖。

新增2项单元测试和1项完整Electron交互测试：实际逐键输入星号、左移、连续文字及组合提交；检查斜体/粗体、磁盘保存与源码，不仅检查即时外观。本轮不修改用户现有文件。

## 验证结果

- lint、严格TypeScript、格式检查与42项单元测试通过。
- 4项强调专项E2E通过，包括此前的闭合星号、整段输入、IME空格/回车及本轮既有分隔符输入。
- 只读DMG安装副本在原构建目录不可用时，全部23项E2E通过，58.8秒；14条相对framework链接有效。
- 原生键盘实测：按两次Shift+8、左移、输入ddd、Cmd+S。实际DOM为em包裹完整ddd，磁盘内容为`*ddd*`（另含文末换行），没有转义星号。测试使用隔离数据和临时文件；中文IME本轮由合成组合事件回归，不冒称额外系统拼音实测。
- Mac APP、ZIP、DMG和Windows x64便携ZIP生成成功；7个关键产物的摘要见artifact-manifest.json。Windows跨平台打包不代表实机运行验收。

当前本机1.0.9有未保存的用户文档与既有恢复内容，因此未强行关闭或替换/Applications内应用。已请求用户保存并退出后再替换。本轮修复包为1.0.10，用户现有内容未改写。安装后回归使用独立DMG副本，不把它描述为本机生产应用已经更新。
