# Chomy 1.0.9 版本验证记录

日期：2026-10-13。验证主机：macOS 26.5.2、Apple M1 Max、arm64。

## 本轮修正

用户解锁后，实际安装版1.0.8原生检查确认菜单栏为Chomy、文件、编辑、段落、格式、显示、主题、窗口、帮助，实际窗口显示全高侧栏、居中大纲标题/空提示、文件名、“— 已编辑”、1词以及侧栏按钮。发现Electron默认role项目仍使用英文Cut、Copy、Paste、Select All、Close Window等。

1.0.9为这些系统角色显式指定中文label，包括应用隐藏/关于、关闭窗口、剪切/复制/粘贴/全选、显示缩放/全屏与窗口最小化/缩放/前置。保留role和默认系统行为，没有替换为无效自定义动作。22项E2E中的窗口测试新增原生角色标签回归。

本轮仅修正原生菜单文字；1.0.8的界面布局、几何与截图记录继续适用，详见[1.0.8记录](validation-1.0.8.md)、[界面对照](../testing/screenshots/chomy-chrome-reference.png)、[技术手册](../developer-handbook.md)。

## 自动化验证

lint、严格TypeScript、格式、40项单元测试通过；开发目录窗口/菜单专项通过。从只读DMG复制、移走原构建后，全部22项E2E通过，58.0秒，包内14条相对framework链接保持可移植。Mac APP、ZIP、DMG校验成功；Windows x64便携ZIP同步生成，跨平台构建不代替Windows实机验收。7个产物摘要见[artifact-manifest.json](artifact-manifest.json)。本机已更新到1.0.9，1.0.8应用保留备份。

## 原生验证与边界

原生窗口左上存在系统紫色窗口共享标记，截图中覆盖交通灯区域；可访问性树仍列出关闭、全屏/缩放和最小化按钮。1.0.9实际原生菜单已确认中文标签；最小化/恢复事件、窗口缩放/恢复和关闭后重新激活已验证。详见[原生记录](../testing/native-acceptance.md)。记录菜单与窗口动作的实际结果，不把自动化的配置读取当成原生视觉通过，也不修改系统共享设置来移除标记。

本轮检查不表示Typora全部菜单项、表格/代码浮层、源码退出方式和全部主题的完整复刻。Windows10/11实机、原生IME、签名与真实云桶仍依照[平台清单](platform-checklist.md)。
