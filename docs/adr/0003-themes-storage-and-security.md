# ADR 0003 — 主题、附件与安全边界

状态：已采用。

主题协议版本独立于应用版本。原生主题由 theme.json 和 theme.css 组成，manifest 校验版本、ID、作者和模式。安装支持目录与 ZIP，限制大小、条目数量、路径、符号链接、压缩输出和 CRC。CSS 通过 AST 解析后限定于文档根，拒绝网络 URL、导入、字体下载与覆盖安全提示的定位。主题不执行代码；第三方主题暂只支持 CSS，包内图片和字体资源未开放。主题ID拒绝点号路径和Windows保留设备名；根兄弟选择器、转义定位/层叠属性和动态定位变量被拦截，文档滚动区域另有paint隔离。

内置明亮、暗色、系统跟随和高对比度主题。用户字号与正文宽度作为独立覆盖配置，不写入主题目录。受限 Typora CSS 迁移转换 #write、常见代码/任务选择器，报告被忽略的私有选择器。用户自行选择有权使用的 CSS；项目不携带 Typora 专有样式。

附件提供复制、原路径引用、云上传三种策略。复制与上传均先写文档相邻 assets，本地默认。原路径引用按文档保存主进程授权记录，只有明确选择的外部资源才可经 chomy-asset 读取，重启保留授权，符号链接改变目的地则拒绝。跨卷引用提示使用复制；移动原文件或另存到新目录不会自动重写引用。

S3 与 Aliyun OSS 使用独立适配器，SDK 只在主进程。凭据使用系统 safeStorage 加密；未提供安全存储时拒绝保存。永久 Markdown URL 必须为用户配置的 HTTPS 公共桶/CDN 根，不生成会过期的签名链接。上传成功后才执行文档插入，失败/取消保留源附件与已写副本。当前一次上传一份，S3 有限重试，60 秒整体超时；取消入口与保留本地副本的直接重试可用，暂无多任务队列和字节进度。

渲染进程 sandbox、contextIsolation、禁用 Node、权限与导航默认拒绝。Preload 使用严格 Schema 和来源验证，禁止任意 fs/shell 接口；文件仅由原生对话框、系统打开事件、文件拖放或已登记 ID 授权。Markdown/HTML/SVG 净化，外部图片默认关闭；开启后经主进程受控协议，HTTPS、15秒超时、20MB响应和4并发上限，省略凭据并拒绝重定向，导出内嵌受控下载结果，脚本和连接由 CSP 拒绝。导出 PDF 使用隔离窗口，禁止脚本；HTML/PDF 内嵌本地图片和字体。
