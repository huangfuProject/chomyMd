# Chomy 1.0.12 版本验证记录

日期：2026-10-14。验证主机：macOS、Apple M1 Max、arm64。

修正此前对用户文件树要求的理解。点击左上图标直接在侧栏显示当前文件系统目录，不弹系统目录选择器。未命名文档优先恢复上次浏览目录，没有记录时使用最近文件目录或系统文稿目录。浏览目录在settings持久化，重启后保持；“切换目录…”为用户主动选择其他目录的独立入口。

文件树包含所有普通文件和真实目录节点，包括空目录；不再只列Markdown并从叶子推导目录。根目录名称显示在列表上方。图片等非编辑文件显示但禁用文本编辑，其ID不加入可打开文档映射。隐藏文件/node_modules/符号链接继续跳过，文件和目录合计逐项限制2000、深度6。

新增未命名文档默认目录、无选择器、重启持久化回归；现有文件树专项增加空目录、图片和根目录名称。FileEntry可选字段及settings可选lastDirectory兼容旧数据。技术手册更新目录规则和预览扩展约束。

## 验证与本机安装

lint、严格类型、格式与42项单元测试通过。只读DMG复制后的应用在原构建不可用时，完整24项E2E通过，58.9秒；14条相对framework链接有效。首次未命名文档在无目录记录时直接浏览文稿目录，回归禁止目录选择器，并验证重启后恢复目录；既有窗口测试覆盖空目录、图片、Markdown、源码与大纲入口。

Mac APP、ZIP、DMG与Windows x64便携ZIP生成，摘要见artifact-manifest.json；Windows跨平台产物不代替实机验收。更新前检查/Applications下应用已不在、无Chomy运行进程，安装1.0.12并正常启动，ASAR与验证构建一致。原生点击左上图标后，实际截图直接显示Documents根名称、文件和子目录，没有弹出目录选择窗口。原生可访问性快照未完整包含文件列表，结论依据实际窗口截图；未将私人文件名或截图写入仓库。用户文档与恢复内容未改写，只持久化浏览目录设置。
