# Chomy 1.0.15 版本验证记录

日期：2026-10-14。验证主机：macOS、Apple M1 Max、arm64。

按用户确认的截图保存方式，新增用户数据目录下的 user-images 持久图片存储。未保存文档可以直接粘贴截图，不弹保存框；本地截图使用经过编码的绝对 file URL，保存及另存 Markdown 保留该路径。时间戳、随机后缀与独占写入避免同一时刻覆盖，恢复、重启和首次保存继续使用明确图片授权。
